## 🌟 Project Overview

The **Web-Based Driving License Issuing Service** is a centralized platform designed to modernize the driving license application process in Sri Lanka. It eliminates the need for citizens to make multiple physical visits to the Department of Motor Traffic (DMT) by providing a secure, efficient, and transparent digital workflow. 

From submitting initial applications and uploading documents to scheduling driving exams and tracking approval statuses, the entire lifecycle is streamlined for both citizens and government officers.

---

## ✨ Core Features & Functions

The system is divided into six major modules, each handling a critical phase of the driving license lifecycle:

### 🏥 1. Medical Test Booking
Allows citizens to schedule and manage mandatory medical examinations prior to applying for a driving license. Applicants can view available medical centers, select time slots, and receive validated digital medical reports from authorized medical officers.

### 📄 2. License Application & Document Uploading
Citizens can submit their driving license applications securely online. This includes filling out personal details and uploading necessary supporting documents (NIC copies, photographs, and medical records). Registration officers can review and verify these documents digitally.

### 💻 3. Driving Exam (Theory) Booking
Upon document approval, applicants can schedule their computer-based theory examination. The system handles capacity management for testing centers, assigns examination slots, and records test results upon completion.

### 🚗 4. Practical Driving Trial Booking
After passing the theory exam, applicants can book their practical driving trial. This module coordinates trial schedules, allows applicants to request department-assigned driving trainers, and provides a platform for Driving Examiners to record trial scores.

### ✅ 5. License Approval & Issuing
Authorized officers can review the complete history of an applicant (document verification, medical clearance, exam results, and trial scores) to approve or reject the issuance of the driving license. Approved applicants are issued their digital credentials.

### 🔄 6. Driving License Renewal
Enables existing license holders to easily renew expired licenses. Applicants can submit renewal requests alongside updated medical reports and photographs without starting the application process from scratch.

## 👥 Roles & Workspaces

The platform features dedicated, secure workspaces tailored to specific user roles:
- **Citizens (Applicants)**
- **Registration Officers**
- **Driving Test Coordinators**
- **Driving Examiners**
- **Driving Trainers**
- **Medical Officers**

## 💻 Getting Started (Frontend)

To run the frontend React application locally:

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
